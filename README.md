# ToDo - E-commerce Project - Django

This is a simple E-commerce product listing project made with Django.

## Features
- Shows 4 products on /products/ page
- Product name, price, description
- Clean UI

## How to Run This Project
1. pip install -r requirements.txt
2. python manage.py migrate
3. python manage.py runserver
4. Open browser and go to: http://127.0.0.1:8000/products/

## Project Structure
- todo/ - main app with products model
- todo_main/ - main project settings
